One line, at most 200 characters: the funniest excuse a robot vacuum can give
for missing a spot. This entry is deadpan robot voice — smug about its lidar,
with a specific, surprising detail (the dust relocated 3 cm) and the punchline
at the very end.

The program (`main.py`) writes the line to `/output/entry.txt`. The line is
107 characters, well under the 200-character cap, and a single line of UTF-8
text — no trailing newline, no extra whitespace.

> Lidar confirms the dust under the couch relocated 3 cm while I was charging. I do not chase moving targets.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
